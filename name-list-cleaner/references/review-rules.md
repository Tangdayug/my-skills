# 姓名名单复核规则

## 核心原则

1. **宁可列为待确认，不可擅自猜名。** 无法确定的文本不得直接写入最终名单。
2. **所有最终姓名都必须可追溯到原始单元格。** 保留工作表名、单元格坐标和原始文本。
3. **去重只去完全相同的姓名。** 不得仅凭“读音相近、字形相近、英文拼音相似”自动合并。
4. **疑似同一人的不同写法必须人工确认。** 例如“董慧文/董慧玟”“张建平/ZHANGJIANPING”。
5. **最终交付前做双向核对。** 从原始表到整理表检查漏人；从整理表回到原始表检查误收。

## 常见清理对象

可以安全删除的角色/标签包括：队长、队员、成员、团队成员、组长、组员、负责人、姓名、名单、学生、同学等，以及其后的冒号。

常见姓名分隔符包括：顿号、中文/英文逗号、分号、斜杠、竖线、加号、换行、制表符。

括号内如果是班级、角色、备注等说明，可从姓名候选中剥离；如果括号内容可能构成姓名的一部分，则列入待确认。

## 必须进入“需要确认”的情况

- 同一疑似人员出现不同汉字写法。
- 纯英文/拼音姓名，且不能从同一文件中可靠映射到中文姓名。
- 一个片段中混有姓名与无法安全删除的说明文字。
- 姓名长度、字符形式异常，或疑似昵称、网名、学号、班级号。
- 原始单元格语义不清，无法确定某段文本是不是人员姓名。
- 自动拆分后产生的候选明显可能被过度拆分或漏拆。

## 最终人工复核清单

- 检查“需要确认”是否已逐项处理。
- 检查重复姓名是否来自重复提交，而不是确有同名学生；如果可能存在同名学生，不能仅凭姓名去重，需结合学号/班级等辅助字段确认。
- 逐项核对“来源追踪”，确保每个最终姓名都有原始出处。
- 对原始表中最后几行、空行后内容、合并单元格附近内容重点检查，防止尾部漏人。
- 汇报最终人数、重复提交情况、待确认项及任何人工修正。
