# 姓名名单格式整理

把杂乱的 Excel 姓名提交整理为一格一姓名的名单，并以“可追溯、可复核、歧义不猜测”为最高优先级。

## 工作流程

1. **识别输入文件。**
   - 若只有一份原始 Excel：整理为新的规范名单。
   - 若同时有原始表和用户已整理表：先判断各自角色，再做双向审计；不要直接覆盖用户结果。

2. **读取全部工作表和全部非空单元格。**
   - 不只扫描第一列或第一张表。
   - 特别检查最后几行、空行之后、合并单元格附近，防止尾部漏项。

3. **执行自动初筛。**
   - 优先运行 `scripts/clean_name_list.py` 生成初步名单、来源追踪和需要确认项。
   - 自动删除明确的角色标签，如“队长、队员、成员、团队成员、组长、组员、负责人”等。
   - 按顿号、逗号、分号、斜杠、竖线、加号、换行等拆分多人姓名。
   - 仅对**完全相同**的姓名自动去重。

4. **人工语义复核自动结果。**
   - 打开并检查原始单元格上下文，而不是只依赖脚本。
   - 遇到疑似姓名不同写法、英文拼音、错别字、昵称、班级/学号混入等，不得自行猜测。
   - 详细规则见 `references/review-rules.md`。

5. **执行双向完整性核对。**
   - **原始 → 最终：** 每个能确定的原始姓名都必须出现在最终名单中。
   - **最终 → 原始：** 最终名单中的每个姓名都必须能追溯到至少一个原始单元格。
   - 对重复提交记录出现次数和来源，但最终姓名表原则上每人一行。
   - 若可能存在“同名不同人”，必须结合学号、班级等字段确认，不能仅凭姓名去重。

6. **生成交付 Excel。**
   默认至少包含：
   - `整理后名单`：A 列标题“姓名”，从 A2 起每格一个姓名，不夹杂序号、角色或备注。
   - `来源追踪`：姓名、出现次数、来源位置、原始内容。
   - `需要确认`：所有不能安全判断或需要用户确认的项。
   - `核对摘要`：最终人数、重复情况、待确认数量及核验说明。

7. **最终回复同时给出文本核对清单。**
   如有任何不确定项，必须在聊天中分点写清楚：
   - 原始写法与来源位置；
   - 为什么不能确定；
   - 需要用户确认什么。
   不要只把问题藏在 Excel 里。

## 准确性红线

- 不因“看起来像同一个人”就自动把不同汉字姓名合并。
- 不把拼音自动替换成中文名，除非文件中存在明确、唯一的对应证据。
- 不删除无法解释的文本后直接假定剩余部分就是姓名；有疑问即列入“需要确认”。
- 不以“总人数差不多”作为完整性证明，必须做来源追踪和双向核对。
- 不宣称“绝对无误”；应说明已经完成哪些校验，以及仍需用户确认的项目。

## 脚本用法

```bash
python scripts/clean_name_list.py input.xlsx output.xlsx --json-report audit.json
```

脚本是初筛与追踪工具，不替代最终人工复核。执行后必须检查“需要确认”和原始内容，再完成最终交付。
